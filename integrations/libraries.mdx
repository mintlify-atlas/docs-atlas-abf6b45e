Ollama provides official SDKs for Python and JavaScript, plus a rich ecosystem of community libraries for other languages and frameworks.

## Official Libraries

Official SDKs maintained by the Ollama team provide the best integration experience.

### Python

<Card title="ollama-python" icon="python" href="https://github.com/ollama/ollama-python">
  Official Python library with async support
</Card>

**Installation:**

```bash
pip install ollama
```

**Usage:**

```python
from ollama import chat

response = chat(
  model='gemma3',
  messages=[
    {
      'role': 'user',
      'content': 'Why is the sky blue?',
    },
  ]
)

print(response.message.content)
```

**Features:**

- Synchronous and async APIs
- Streaming support
- Type hints and IDE autocompletion
- Complete API coverage (chat, generate, embeddings, etc.)

### JavaScript

<Card title="ollama-js" icon="javascript" href="https://github.com/ollama/ollama-js">
  Official JavaScript/TypeScript library for Node and browsers
</Card>

**Installation:**

```bash
npm i ollama
```

**Usage:**

```javascript
import ollama from "ollama";

const response = await ollama.chat({
  model: "gemma3",
  messages: [
    { role: "user", content: "Why is the sky blue?" }
  ],
});

console.log(response.message.content);
```

**Features:**

- Works in Node.js and browsers
- TypeScript support with full type definitions
- Promise-based async API
- Streaming support
- Complete API coverage

## REST API

If there's no SDK for your language, you can use the REST API directly.

### Example: Chat Endpoint

```bash
curl http://localhost:11434/api/chat -d '{
  "model": "gemma3",
  "messages": [{
    "role": "user",
    "content": "Why is the sky blue?"
  }],
  "stream": false
}'
```

### Example: Generate Endpoint

```bash
curl http://localhost:11434/api/generate -d '{
  "model": "gemma3",
  "prompt": "Why is the sky blue?",
  "stream": false
}'
```

### Example: Embeddings

```bash
curl http://localhost:11434/api/embeddings -d '{
  "model": "nomic-embed-text",
  "prompt": "The sky is blue because of Rayleigh scattering"
}'
```

<Tip>
  See the [API documentation](/api/introduction) for complete endpoint details.
</Tip>

## OpenAI Compatibility

Ollama provides OpenAI-compatible APIs, so you can use existing OpenAI SDKs:

```python
from openai import OpenAI

client = OpenAI(
  base_url='http://localhost:11434/v1',
  api_key='ollama',  # required but unused
)

response = client.chat.completions.create(
  model="gemma3",
  messages=[
    {"role": "user", "content": "Why is the sky blue?"}
  ]
)

print(response.choices[0].message.content)
```

## Building Your Own SDK

If you're building a new Ollama SDK:

<Steps>
  <Step title="Study the REST API">
    Read the [API documentation](/api/introduction)
  </Step>
  <Step title="Check existing SDKs">
    Review [ollama-python](https://github.com/ollama/ollama-python) and [ollama-js](https://github.com/ollama/ollama-js) for patterns
  </Step>
  <Step title="Support streaming">
    Implement streaming for chat and generate endpoints
  </Step>
  <Step title="Add type safety">
    Provide strong types/schemas for requests and responses
  </Step>
  <Step title="Handle errors">
    Gracefully handle network errors and API errors
  </Step>
  <Step title="Write tests">
    Use Testcontainers or a local Ollama instance
  </Step>
  <Step title="Document examples">
    Provide clear usage examples in your README
  </Step>
  <Step title="Submit to community">
    Open a PR to add your SDK to the [Ollama README](https://github.com/ollama/ollama#community-integrations)
  </Step>
</Steps>
